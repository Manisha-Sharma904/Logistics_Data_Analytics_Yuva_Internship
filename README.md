# Logistics_Data_Analytics_Yuva_Internship
<br>
The goal of week 1 is to establish a strategic planning framework for the logistics analytics internship project. This week focuses on defining the logistics scenario, identifying key performance indicators (KPIs) for supply chain performance, conducting a preliminary literature survey, and outlining relevant data science concept for exploratory analysis. The aim is to build a foundation for data-driven planning to improve last-mile delivery efficiency and reduce operational cost
